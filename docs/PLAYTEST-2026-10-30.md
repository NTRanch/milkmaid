# Playtest record — Milkmaid, 2026-10-30 (v1.0.0 gate)

Sandbox playtest of record: the game's own demo policy plays the
shipped JS core (`tools/playtest.mjs`), so the artefact under test is
the artefact that ships. The seahawk pass on primo is the follow-up
named in the breakage log (B-2) — the primo tunnel was down for the
whole build night.

The demo policy is deliberately ordinary — hold, rotate on heat, pinch
the fuller side — so these numbers are evidence the rounds are
generously but honestly tuned, not that a script was fitted to them.
Round 3's first design point (650 ml at production 26) was proven
unreachable by model-exact simulation during gating and retuned before
release (breakage B-4).

## Gates behind the playtest

- Conformance: `tools/conformance.mjs` — the shipped JS kernel
  reproduces every kernel vector exactly: 14 scenarios, 30 checkpoints
  (FNV-1a digest + full snapshot), 11 efficiency-curve points, 12 RNG
  outputs, method/level tables identical to `src/kernel.mojo`'s.
- Unit tests: `tools/tests.mjs` — 14 passed (6 validation, 8
  adversarial), including hand-derived anchors (the pinch pressure/
  arousal ramp; the culmination-boundary switch semantics) and exact
  volume conservation with production disabled.
- Bridges: `tools/settings-check.mjs` — settings + chart-archive
  bridges round-trip, hostile archive values clamp, settings reachable
  from boot with no progression.
- Performance: `tools/perf.mjs` — 0.010 ms/step (10,000 steps + frames
  in 104 ms) against a 0.2 ms/step budget; `web/index.html` 39,470 B.

## Visual gate (D-221) — SHOULD vs seen

Frames extracted from the FINAL preview MP4s
(`docs/previews/level-1-milkmaid.mp4` @3 s,
`docs/previews/level-2-milkmaid.mp4` @8 s) and inspected at viewing
size.

SHOULD: round name + countdown; yield vs target with circuit pips; a
LET-DOWN banner naming the active method while one runs; two tanks
with fill levels, the addressed side tagged IN SERVICE; pressure and
arousal gauges with the threshold tick; the four-method row with heat
bars and per-method let-down counts; the fluid-timeline strip; a
grown-capacity readout; the input hint.

SEEN: every element present and legible in both frames. Two findings,
both closed or filed:

1. The PRESS/RISE gauge labels overlapped on the first capture
   ("PRESS…SE"). Labels moved apart and set smaller; re-captured and
   re-inspected — PASS (breakage B-5).
2. The shared estate preview rasteriser renders its bitmap "2" close
   to a "5" at 480 px, so the 420.0 ml target reads as "450.0" in
   preview frames. The data is proven correct by conformance and the
   playtest; the shipped page renders text with a real canvas font.
   The shared raster file was deliberately not forked (breakage B-6).

Verdict: PASS. The Owner's eye supersedes this gate on review.
